# Prompt Improve Loop (Ralph-loop с eval-гейтом)

Цикл авто-улучшения промптов: headless-агент выдвигает по одной гипотезе
правки промпта, гейт из тестов решает — оставить или откатить. Методология
из практики GigaChain/Сбер (+22,5 п.п. качества только промптингом) и
Ralph-loop Джеффри Хантли. Задача: [#517](https://github.com/chatman-media/lead-engine/issues/517).

## Идея

Три обязательных свойства цикла:

1. **Маленькие шаги, свежий контекст.** Каждая итерация — новый процесс
   `claude -p` без памяти прошлого разговора. Память между итерациями —
   журнал `prompt-loop-log.md`: агент читает его и не повторяет уже
   испробованные гипотезы (включая отклонённые).
2. **Backpressure.** Гейт = typecheck + тесты пакетов с промптами
   (`kb`, `sales`, `conversation-engine`) + опциональный живой бенчмарк.
   Без гейта цикл деградирует: правки накапливаются без контроля.
3. **Принять/откатить, без полумер.** Зелёный гейт → commit. Красный →
   `git reset --hard`, в журнал пишется отклонённая гипотеза (чтобы не
   пробовать её снова).

## Запуск

```bash
# чистое дерево, отдельная ветка
git checkout -b quality/prompt-loop

ITERATIONS=5 ./scripts/prompt-improve-loop.sh

# сузить зону поиска
TARGET="reflect/fact-check промпты в packages/kb/src/prompts" ./scripts/prompt-improve-loop.sh

# добавить живой бенчмарк в гейт (нужны LLM-ключи)
GATE_EXTRA_CMD="bun run quality:tool-regressions --file corpus.jsonl" \
  ./scripts/prompt-improve-loop.sh
```

Переменные: `ITERATIONS` (default 5), `TARGET` (зона поиска гипотез),
`GATE_EXTRA_CMD` (доп. команда в гейте; ненулевой exit = откат),
`LOG_FILE`, `CLAUDE_BIN`.

## Как добавить свой бенчмарк в гейт

Гейт — функция `gate()` в `scripts/prompt-improve-loop.sh`. Любая команда с
ненулевым exit-кодом при деградации подходит:

- **Tool-regressions** (детерминированный реплей, без LLM):
  `bun run quality:tool-regressions --file <corpus.jsonl>` — корпус кейсов
  из quality-lab.
- **Golden evals** (офлайн, на фейках — проверяют контракт промпта, не
  качество): уже в гейте через `bun run --cwd packages/kb test`.
- **Живой eval** (реальный LLM, единственный сигнал по качеству ответов):
  свой скрипт, который гоняет сценарии и сравнивает метрику с бейзлайном —
  подключается через `GATE_EXTRA_CMD`. Без него цикл гарантирует только
  «не сломали», но не «улучшили» — для полноценного прогона ключи обязательны.

## Ограничения и безопасность

- Скрипт коммитит **только локально** и никогда не пушит: ревью серии
  коммитов перед merge обязателен.
- Требует чистого рабочего дерева; откат делается через `git reset --hard`
  и `git clean -fd packages apps` — не запускать поверх несохранённых правок.
- Агенту запрещено (промптом) трогать логику/типы/тесты — только текст
  промптов. Гейт это дополнительно страхует: правка сигнатуры уронит typecheck.
- Журнал коммитится даже при откате — отклонённые гипотезы не повторяются.
