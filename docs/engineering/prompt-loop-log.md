# Журнал prompt-improve-loop

Гипотезы цикла авто-улучшения промптов (`scripts/prompt-improve-loop.sh`,
[#517](https://github.com/chatman-media/lead-engine/issues/517)). Каждая
запись: вердикт (`kept` — гейт зелёный, закоммичено; `reverted` — гейт
красный, откачено; `no-op` — правок не было) и гипотеза одной строкой.

Агент в цикле читает этот файл и не повторяет уже испробованное.
Не редактировать вручную, кроме чистки явно устаревших записей.
