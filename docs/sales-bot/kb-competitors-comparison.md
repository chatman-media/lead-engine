## Подробно

### ManyChat
**Что умеет:** маркетинговые flow-последовательности, broadcast, рекламные сценарии.
**Проблема:** не понимает свободный диалог. Если кандидат напишет «а что с визой?» — упадёт в fallback. Это не квалификация, это анкета с кнопками.
**Цена:** $15+/мес, но нет LLM — нет интеллекта.

### Intercom Fin for Sales
**Что умеет:** квалификация входящих лидов на сайте, хорошая интеграция с CRM.
**Проблема:** нет нативного Telegram. $0.99 за каждый resolution — при 300 заявок/мес = $297 только за бота.
**Для нас:** не конкурент на рынке RU/CIS/MENA где Telegram доминирует.

### Tidio / Lyro
**Что умеет:** AI-чат на сайте, омниканальный inbox.
**Проблема:** Telegram только через Zapier (нестабильно, задержки). Нет NEPQ-методологии — просто FAQ.

### Crisp
**Что умеет:** inbox + co-pilot (предлагает ответы оператору).
**Проблема:** co-pilot ≠ автономный агент. Оператор всё равно нужен 24/7. Нет Telegram.

### Самописный GPT-бот
**Что умеет:** что угодно, но нужен разработчик.
**Проблема:** нет платформенной инфраструктуры: нет multi-tenant, нет billing, нет operator inbox, нет воронки, нет audit log. Разработка стоит $5–20K, поддержка — постоянно.

## Почему lead-engine выигрывает в RU/CIS/MENA

1. **Telegram-first** — единственная платформа, где Telegram — первый, а не последний канал
2. **BYOK** — при 300 заявок/мес Intercom = $297, lead-engine = $99 + ~$10 OpenAI
3. **NEPQ встроено** — не просто отвечает на вопросы, а ведёт по воронке продаж
4. **Без программиста** — 15 минут до работающего бота, не 15 дней
5. **RU/CIS локализация** — русский интерфейс, понимание рынка
