# Настройка sales-бота: пошаговый гайд

Этот бот продаёт Lead Engine рекрутёрам прямо в Telegram.
Мета-демо: человек видит продукт в действии пока ему его продают.

## Шаг 1 — Создать Telegram-бот

1. Открыть @BotFather в Telegram
2. `/newbot` → имя: `lead·engine консультант` → username: `leadengine_sales_bot` (или любой свободный)
3. Скопировать токен

## Шаг 2 — Зарегистрировать тенант

1. Зайти на `app.leadengine.app/signup` (или localhost)
2. Email: `sales@leadengine.app`, slug: `leadengine-sales`
3. Пройти онбординг

## Шаг 3 — Подключить Telegram-канал

Settings → Channels → Telegram Bot → вставить токен → Connect

## Шаг 4 — Настроить LLM

Settings → LLM:
- Provider: OpenAI
- Model: `gpt-4o` (рекомендуется для продаж — лучший reasoning)
- API Key: ваш ключ OpenAI

## Шаг 5 — Загрузить базу знаний

Settings → База знаний → загрузить файлы (один за другим):
- `kb-product-overview.md`
- `kb-case-study-uae.md`
- `kb-objections-and-faq.md`
- `kb-competitors-comparison.md`

## Шаг 6 — Создать воронку

Settings → Funnel → Seed template → выбрать `leadengine_sales_v1`

## Шаг 7 — Настроить системный промпт

Settings → Styles → Edit:
- Скопировать содержимое `system-prompt.md` (блок в ```)
- Заменить `[SIGNUP_URL]` на реальный адрес регистрации
- Сохранить

## Шаг 8 — Протестировать

Написать боту: «Привет, расскажи про Lead Engine»

Ожидаемое поведение:
1. Бот представляется как Алекс
2. Задаёт ситуационный вопрос про объём заявок
3. Выявляет боль
4. Предлагает триал после квалификации

## Использование в GTM

- **YouTube-видео:** в конце каждого видео — «напишите @leadengine_sales_bot — Алекс ответит»
- **Холодные DM:** вместо ссылки на сайт → ссылка на бот (меньше трения)
- **Партнёры:** каждый партнёр направляет своих клиентов в этот бот → лид квалифицируется автоматически
- **Инвесторам:** «вот наш sales-бот — он работает на нашем же продукте»

## Мониторинг

Dashboard → «Закрыто ботом» — показывает сколько лидов дошло до `trial_started`.
Цель: конверсия DM → триал > 15%.
