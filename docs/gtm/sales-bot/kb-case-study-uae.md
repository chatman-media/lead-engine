# Кейс: рекрутинговое агентство, ОАЭ

## Ситуация до Lead Engine

Агентство занималось подбором персонала в сфере гостеприимства (официанты, повара, аниматоры) для работодателей в ОАЭ. Кандидаты — преимущественно из России, Украины, Казахстана, Узбекистана. Основной канал входящих — Telegram.

**Проблемы:**
- 200–300 заявок в месяц, 1–2 оператора
- Заявки в 22:00 и выходные → к утру кандидат уже нашёл другое агентство
- Операторы тратили 3–4 часа в день на первичные вопросы («а какие документы нужны?», «а сколько платят?»)
- Анкеты заполнялись вручную через Google Forms — половина не заполняла

## Что сделали

Подключили Lead Engine к Telegram-боту агентства:
- Загрузили описания вакансий и требования в базу знаний
- Настроили воронку: знакомство → параметры (рост/вес/гражданство) → документы → визовая анкета
- Подключили WhatsApp для арабоязычных кандидатов

## Результат

- Бот обрабатывает **300+ входящих заявок в месяц** без участия операторов на первичном этапе
- Операторы подключаются только к кандидатам, прошедшим квалификацию (≈ 30% от потока)
- Время первого ответа: **< 30 секунд** вместо 2–8 часов
- Заполняемость анкет выросла с ~50% до ~85% (бот задаёт вопросы последовательно в диалоге)
- Операторы освободили 3+ часа в день на работу с горячими кандидатами

## Технические детали

- Канал: Telegram bot + WhatsApp Cloud API
- LLM: OpenAI GPT-4o mini (BYOK — клиент платит OpenAI напрямую)
- Воронка: 12 этапов от первого контакта до визовой анкеты
- Функция перехвата: оператор подключается к сложным случаям в один клик
