Channel-agnostic contract: `ChannelAdapter`, `Inbound`, `OutboundEnvelope`, `ChannelCapabilities`. The pluggable layer for Telegram / WhatsApp / web-chat / etc.

Part of the [**lead-engine**](https://github.com/chatman-media/lead-engine) monorepo — a multi-tenant SaaS platform for AI sales bots on Telegram / WhatsApp.

## Install

```bash
bun add @chatman-media/channel-core     # Bun
npm install @chatman-media/channel-core # npm / pnpm / yarn
```
