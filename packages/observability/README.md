`JsonLogger` + Prometheus metrics (counters, histograms) for apps/api and apps/worker. Zero npm deps — hand-rolled Prometheus text format.

Part of the [**lead-engine**](https://github.com/chatman-media/lead-engine) monorepo — a multi-tenant SaaS platform for AI sales bots on Telegram / WhatsApp.

## Install

```bash
bun add @chatman-media/observability     # Bun
npm install @chatman-media/observability # npm / pnpm / yarn
```
