WhatsApp Cloud API channel adapter (Meta Graph) — text + media via webhook + Graph API send.

Part of the [**lead-engine**](https://github.com/chatman-media/lead-engine) monorepo — a multi-tenant SaaS platform for AI sales bots on Telegram / WhatsApp.

## Install

```bash
bun add @chatman-media/channel-whatsapp     # Bun
npm install @chatman-media/channel-whatsapp # npm / pnpm / yarn
```
